Custom rule

Selected cell: r = 0, c = 0 (row 1, column 1). Coordinates are zero-based in the rule.

Visual helpers: highlight_cells([[r, c], ...]) outlines cells; highlight_row(r), highlight_column(c), and highlight_box(r, c) outline a whole row, column, or 3×3 box. Coordinates run from 0 to 8. These helpers only draw on the board; your function must still return true or false to enforce a rule. The drawing follows the selected cell.

Possible next helpers: draw_line(cells) to connect cells in order, shade_cells(cells, color) to group cells by color, and label_cell(r, c, text) to show a small clue in a cell.

About Sudoku Studio

Why I built this

There are plenty of websites for Sudoku variants, but each one covers a single variant: one for Anti-Knight, another for X-Sudoku, another for Non-Consecutive. Each has its own layout, its own controls and its own idea of what a pencil mark is. I couldn’t find one place that handled them all.

So I made one. A single board and a single set of tools, with the variant being just a rule you pick.

What you can do here

  • Play any built-in variant — Standard, Anti-Knight, Anti-King, Diagonal and Non-Consecutive.
  • Recreate an external puzzle — for example one from a championship or another site — by typing its givens onto the board on the first screen, then play it here with the same tools.
  • Use the utilities on any puzzle — Auto notes fills candidates according to the active variant’s rules, and selecting a digit highlights it everywhere, including inside pencil notes.
  • Write your own rule as a small JavaScript function and play it right away.

Playing an external puzzle

  1. Pick the variant the puzzle uses.
  2. On the first screen, select a cell and type each given digit to recreate the puzzle.
  3. Press Start puzzle. The givens lock and the timer starts.

Only given digits and the built-in rules are supported. Extra clues such as cages, arrows or thermometers can’t be set up here.

Shortcuts

  • 1–9 place a digit, or a note when Notes is on
  • Backspace erase · P toggle notes · Ctrl+Z undo
  • Arrow keys move the selection

Privacy

Everything runs in your browser. Puzzles you enter or import are never uploaded. The only thing saved is your light/dark theme choice.
